一、玩家怎么玩

1打开链接 — 进入戳戳乐主界面，看到格子墙，每个格子都是未揭开状态。
2输入口令 — 点击任意格子，输入管理员发的口令，点击确认。
  • 口令正确且有次数 → 格子戳开，显示奖品
  • 口令错误 / 次数用完 / 格子已开 → 对应提示
3查看结果
  • 中奖：彩带飘落 + 金色流光 + 奖杯动画，显示奖品和中奖人
  • 谢谢惠顾：简洁灰色"再接再厉"窗口，无特效
4生成海报 — 中奖后点「✨ 生成海报」，或主界面点「🎨 海报」查看全部。
  • 长按图片 → 保存到相册 | 左右箭头 → 切换海报
  • 保存当前 → 下载单张 | 全部保存 → 批量下载
5已戳格子 — 显示奖品内容，底部小标签显示戳开者（口令前两字）。

二、管理员怎么操作

管理员密码：zhaomi2026 — 主界面点「⚙ 管理」输入密码进入

2.1 奖品设置（🎁 奖品标签）

调整格子：设置行数列数（1~10），点「应用」重新排列，原内容保留。

设置奖品：逐个填写格子内容。

  • 填"一等奖" → 中奖 | 填"谢谢惠顾"或留空 → 未中奖

提示修改后自动保存，无需手动操作。

2.2 口令管理（🔑 口令标签）

作用：控制谁能戳格子，只有正确口令才能戳。

添加：输入口令名称 + 可戳次数，点「添加」。如"小明123"次数3 → 可戳3格。

删除：口令列表右侧「删除」按钮，删除后立即失效。

不设口令：未添加任何口令时，所有人可直接戳。

2.3 戳奖日志（📋 日志标签）

自动记录每次戳奖：

字段说明
口令戳奖人使用的口令
奖品戳到的奖品内容
格子第几个格子
时间戳奖时间（北京时间）

按时间倒序排列。点「清空日志」可清除记录，不影响奖品和口令。

2.4 其他操作

清空记录（橙色）：重置戳开状态为未开，保留奖品和口令，相当于新一轮。

重置所有（红色）：清空一切，恢复初始空白。慎用！

三、快速上手流程

管理员首次使用：

  1. 点「⚙ 管理」，输入密码 zhaomi2026
  2. 「🎁 奖品」标签：设行列数，填奖品
  3. 「🔑 口令」标签：添加口令+次数
  4. 关闭面板，把口令发给参与者

玩家参与活动：

  1. 打开链接，点格子，输入口令
  2. 查看结果，点「✨ 生成海报」保存
  3. 继续戳其他格子（次数没用完的话）

管理员活动后：

  1. 「📋 日志」标签查看戳奖记录
  2. 新一轮活动：点「清空记录」重置
